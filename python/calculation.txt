#Pythonの基本的な計算
x + y    x と y の和
x - y    x と y の差
x * y    x と y の積
x / y    x と y の商
x // y   x と y の商を切り下げたもの
x % y    x / y の剰余
-x       x の符号反転
+x       x そのまま
x ** y   x の y 乗

例：
print("5 + 7 = " + str(5 + 7))
>> 5 + 7 = 12

print("4 * 8 = " + str(4 * 8))
>> 4 * 8 = 32

print("15 / 2 = " + str(15 / 2))
>> 15 / 2 = 7.5

print("15 // 2 = " + str(15 // 2))
>> 15 // 2 = 7

print("15 % 2 = " + str(15 % 2))
>> 15 % 2 = 1
算子の // は商の整数部分だけを取得する。
