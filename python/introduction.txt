#Pythonとは
Perlから派生した汎用プログラミング言語。1991年に設計された。
プログラムを1行ずつ解釈しながら実行するインタプリンタ方式を採用している。
また、Pythonは「オブジェクト指向言語」の1つであり、オブジェクト指向開発という「データと処理」を1セットとしてプログラムを組み立てていく開発手法に適した言語の一つである。
オブジェクト指向言語には、Python の他にもJava、C#、Ruby、PHP などが挙げられる。

##変数
Python を含むプログラミング言語では、「変数」を使ってデータを一時的に保存し、後で参照や操作を行うことができる。
変数を作ることを「変数を宣言する」と言う。
初めて変数にデータを入れることを「変数の初期化」と言う。
変数名を決める際のルール
\- 数字から始めることは不可
\- 大文字と小文字は区別される
\- 以下の予約語(既に役割が決まっている単語)は変数名にすることはできない

##データ型
「データ型」とは、データ（値やオブジェクト）の型。


データ型には以下の種類があります。

\- 数値型
int 型(整数)
float 型(少数)
\- 文字列型(string 型)
\- ブール型(boolean 型)
\- list	リスト型	[1, 2, 3], [‘apple’, ‘banana’, ‘cherry’]
\- tuple	タプル型	(1, 2, 3), (‘apple’, ‘banana’, ‘cherry’)
\- dict	辞書型

ブール型とはTrue または False の2つのうち、どちらか1つを持つ型のこと。

Python は「動的型付け言語」に分類され、変数を宣言する際にデータ型を指定する必要は無い。
Python が自動的にデータを判断してくれる為。RubyやPHP,JavaScriptも動的型付け言語である。

##記述のルール
Pythonは、コードが一行ずつ独立している。

Pythonでは、CやHTMLなどのように行の終わりにセミコロン（;）を加えることは必須ではない。
コードが読みやすくなるよう、段落分けをするために空行を使用して、各セクションを明確に区切ると良い。
しかし、複数行にまたがるようなプログラミングができないと読みにくいものになってしまうため、複数行での表現もできるようになっている。
Pythonでは、インデント（字下げ）によってコードのブロックを表現する。
インデントによって読みやすくする効果もある。
