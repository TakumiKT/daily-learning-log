#標準入力とは

##Rubyにおける「標準入力」の英語は Standard Input で、略してstdinと呼ばれます。プログラムがキーボードやファイルからデータを受け取るためのストリーム

Q. a b 入力値最終行の末尾に改行が１つ入ります。 文字列は標準入力から渡されます。 aとbを足した数を出力しなさい。
A. 
a, b = gets.split.map(&:to_i)
puts a + b

入力で a b のように、半角スペース区切りで 2 つの整数が渡される。

例えば、
3 5
と入力されたら、
a = 3
b = 5
なので、
8
を出力する。

###gets
標準入力から 1行読み込む という意味。
たとえば入力が
3 5
なら、gets で "3 5\n" のような文字列を受け取る。

###split
gets.split
split は、文字列を空白ごとに分けるメソッド。

"3 5".split
は
["3", "5"]
になる。
この時点ではまだ 文字列。

###map(&:to_i)

gets.split.map(&:to_i)

map(&:to_i) は、配列の各要素を整数に変換する。
["3", "5"]は、

[3, 5]
になる。

###a, b =
a, b = gets.split.map(&:to_i)

列の中身をそれぞれ変数に入れている。
a = 3
b = 5
という状態になる。

###puts a + b

puts a + b

###全体の流れ

入力:
3 5

処理:
gets で "3 5" を受け取る。
split で ["3", "5"] にする。
map(&:to_i) で [3, 5] にする。
a = 3, b = 5
puts a + b で 8 を出力
完成コード
a, b = gets.split.map(&:to_i)
puts a + b
